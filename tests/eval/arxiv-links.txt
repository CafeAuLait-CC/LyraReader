# Evaluation corpus for the citation/reference index (task T4.10).
#
# The PDFs are NEVER committed. This file is the only record of the corpus:
# ./scripts/fetch-eval-papers.sh downloads it into the git-ignored eval-papers/ directory,
# exactly like pdf-samples/ and vendor/. CI never needs the PDFs — when they are absent the
# harness says the evaluation did not run instead of passing quietly.
#
# These twenty papers are deliberately different from the twelve in pdf-samples/, which is the
# corpus the parser was tuned on and which therefore flatters it. That corpus includes both single- and two-column papers; this set adds
# different typography and citation styles: superscript citations, alphanumeric labels,
# author-year lists of several hundred entries, romanized non-Latin names.
#
# Line format (the fetch script reads the first field as the arXiv id):
#
#   <arxiv-id>  family=<template> | body=<page layout> | cite=<in-text citation style> |
#               bib=<reference-list typography> | head=<heading and list structure> |
#               doc=<measured document facts> | why=<what this paper is here to catch>
#
# `bib` records the reference-list layout, independently of the body layout.
# Every property below was checked against the fetched PDF (pdftotext layout/heading probes plus
# the harness's own link-annotation count), not inferred from the venue — the arXiv version of a
# CVPR paper is not always the CVPR layout, and 1512.03385 is exactly that trap.
